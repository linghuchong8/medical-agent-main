## 二、文档地图（按场景选择）

### 场景 1：我刚拿到项目，想了解它是什么
**阅读**：`README.md` → `docs/代码解释.md` 的第一、二节
- 了解它是"医疗领域 Agent"项目，5 大能力：智慧问诊 / 报告解读 / 药物 / 知识文档 / 运营数据。
- 了解技术栈与目录结构。

### 场景 2：我要在全新机器上部署
**阅读**：`docs/操作文档.md` 的「三、部署」章节 → `deploy/DEPLOYMENT.md`
- Windows 用户：双击 `start_dev.bat`。
- Linux 用户：`bash deploy/start_dev.sh`。
- 需要先配置 `.env` 中的 DEEPSEEK_API_KEY。

### 场景 3：我是开发，要改代码/加功能
**阅读**：`docs/开发上手指南.md`（实操、任务驱动）→ `docs/代码解释.md`（重点第三、四、五节）
- 修改对话逻辑 → `src/agents/supervisor_agent.py`
- 修改接口 → `src/modules/chat.py`
- 修改页面样式/文案 → `src/modules/chat.py` 内 `_CHAT_HTML`
- 修改数据模型 → `src/modules/medical/model.py` + alembic 迁移

### 场景 4：我是运维，日常启动/排查故障
**阅读**：`docs/操作文档.md` 的「五、日常运维」「六、故障排查」 → `deploy/DEPLOYMENT.md` 第八节
- 启动/停止/看日志/健康检查命令速查。

### 场景 5：我要写/改脚本
**阅读**：`docs/脚本说明书.md`
- 部署脚本：`deploy/` 下 8 个脚本。
- 数据初始化脚本：`scripts/` 下 2 个脚本。

## 四、重要配置项速查

详见 `docs/操作文档.md`「四、环境变量配置」。核心必填项：

| 配置项 | 必填 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | ✅ | DeepSeek 对话密钥，不填对话返回 401 |
| `DB_*` | 默认可用 | PostgreSQL 连接（默认 medical/medical123@localhost:5432/medical_db） |
| `REDIS_*` | 默认可用 | Redis 连接 |
| `MINIO_*` | 默认可用 | MinIO 连接 |
| `MILVUS_*` | 默认可用 | Milvus 连接 |
| `NEO4J_*` | 默认可用 | Neo4j 连接 |
| `LOG_LEVEL` / `LOG_DIR` | 可选 | 日志级别与目录 |

## 六、安全提醒

1. `.env` 中的 `DEEPSEEK_API_KEY` 属于敏感凭据，**不应提交到公开仓库**（本项目 `.env` 已被 .gitignore 忽略，但工作区中已存在）。
2. `src/utils/jwt_utils.py` 中 SECRET_KEY 为硬编码，生产环境务必改为环境变量注入并轮换。
3. 生产环境部署前请修改所有默认口令（PostgreSQL / Redis / MinIO / Neo4j）。
